# 群聊身份归属

适用于本机 AstrBot 4.29.3 的群聊身份增强插件。

- 群聊背景逐条携带发送者 ID、昵称、消息 ID。
- 引用原作者与当前发言者分开，@ 对象不充当发言者。
- 当前输入的身份标记随对话保存，避免下一位群友继承上一位的身份。
- 保留群聊共享上下文及框架原有图片、引用处理，不清空历史，不发送额外消息。
- 私聊保持原行为；不自动重写旧记忆或猜测旧历史的作者。

插件包装内置群聊上下文实例的 `_format_message` 方法，停用时恢复。该接口属于
框架内部接口，因此暂限 4.29.x；升级 AstrBot 后需要重新核对兼容性。
没有修改 AstrBot 核心源文件。新消息会获得完整标注；加载前已经缓存的背景保持原样。

同时建议开启配置文件的「用户识别」，将「群聊消息记录注入上下文」的最大条数设为 50。
这增强模型可用的依据，不保证模型在每次复杂多人对话中都判断正确。
